# 💰 Семейный бюджет

Планировщик бюджета для двоих — «Я» и «Жена». Каждая операция помечается:
**мои / её / общие**. Без регистраций и облаков: один сервер, одна база,
открывается с любого телефона, ставится на главный экран как приложение (PWA).

## Возможности

- ➕ Доходы и расходы: сумма, категория, дата, комментарий, чья операция
- 📊 Дашборд месяца: баланс, разбивка «я / жена / общие», категории с лимитами
- 📏 Лимиты по категориям с прогресс-барами (оранжевый при 80%, красный при превышении)
- 🔁 Повторяющиеся платежи — создаются автоматически в нужный день месяца
- 🎯 Совместные цели-копилки с вкладом каждого
- 📈 График доходов/расходов за 6 месяцев
- 📄 Экспорт в CSV (дружит с русским Excel)
- 🌙 Тёмная тема, адаптивный интерфейс, PWA

## Стек

**Node.js 22 + Express + встроенный `node:sqlite`** — единственная зависимость
`express`, никакой сборки фронтенда (чистые HTML/CSS/JS в `public/`).

## Запуск

```bash
npm install && npm start    # → http://localhost:3000
```

Требуется Node.js ≥ 22.5. База создаётся автоматически в `data/budget.db`.

## Структура

```
server.js   — Express: REST API + статика
db.js       — слой данных: схема SQLite и запросы
public/     — фронтенд: index.html, app.js, styles.css, PWA (manifest, sw.js)
data/       — budget.db (в .gitignore; бэкап = копия файла)
```
